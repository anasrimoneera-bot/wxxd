# 1688 货源助手（Chrome / Edge 插件）

在你自己登录的浏览器里，直接在 1688 网页上给微信小店助手里的商品找货源：

1. **选商品**：点插件图标，登录你的网站，选一个还没有货源的商品（店铺商品或商品云库）。
2. **搜同款**：点「打开 1688 找货源」（主图链接已复制），在 1688 用图片搜索 / 关键词搜索。
3. **AI 核对**：在搜索结果页，右下角面板点「AI 核对本页商品」。网站用 Gemini 比较主图和标题，
   每个商品标上 同款 / 相似 / 不同；**最优**（同款里销量最高的，没有同款就选最便宜的相似款）会被橙色框出来。
4. **设为货源**：打开最优商品的详情页，面板会读出每个 1688 规格的价格和运费，自动对应到我们的规格
   （可以手动改），点「设为货源」。货源价和运费会写入商品云库和所有店铺里的同一商品，
   公式改价和订单采购成本按「货源价 + 运费」计算。

插件只读取 1688 页面，不会在 1688 上点击、下单或提交任何东西。

## 安装

1. 把整个 `1688-extension` 文件夹下载到电脑上。
2. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`），打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择 `1688-extension` 文件夹。
4. 点浏览器右上角的拼图图标，把「1688 货源助手」固定到工具栏。

## 设置 Gemini

AI 核对需要 Gemini API Key：网站 **系统设置 → 视觉 AI (Gemini)** 里填写（在 Google AI Studio 创建），
点「测试」确认可用。Key 只保存在你的服务器上，插件里不保存。

## 说明

- 1688 页面结构经常变化，如果某个页面读不到价格或规格，可以在面板里手动填写，然后告诉开发者页面地址。
- 搜索结果页的图片要先加载出来（往下滚动一下）才能核对。
