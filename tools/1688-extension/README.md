# 1688 货源助手（Chrome / Edge 插件）

在你自己登录的浏览器里，直接在 1688 网页上给微信小店助手里的商品找货源：

1. **选商品**：点插件图标，登录你的网站（网站地址、账号和密码可以保存在这台电脑上，下次直接点登录；
   保存了密码的话，登录过期时插件会自动重新登录），勾选最多 10 个还没有货源的商品（店铺商品或商品云库）。
2. **批量找货源**：点「批量找货源」，插件默认打开 1688「一件代发」搜索页，切到「搜图片」，一次上传最多 10 个商品主图（点击上传 → 确定），
   再逐个点上传的图片打开它的搜索结果，你在卡片上点「选为货源」或在面板里点「跳过」，自动接着下一张。
   如果页面上找不到上传图片的那一排，就改为一个一个上传主图搜索。插件弹窗里「搜图页面」也可以选旧的「找品」页，流程如下：
   插件打开 1688「找品」页面（air.1688.com），自动：
   从你的网站取 10 个商品主图，用「批量图搜」当作图片文件上传（1688 读不了其他网站的图片链接）→ 切到大图模式 →
   逐个点「已上传图片」里的每张图，打开它的搜索结果。每个结果卡片上有「选为货源」按钮：
   你看中哪个就点哪个，不合适就在面板里点「跳过」，插件自动转到下一张图。可以随时「停止」，
   之后点「继续未选的」或单个商品的「重选」。点面板里商品的小图可以把我们的主图放大显示在旁边，
   方便和 1688 的图对照，再点一次取消；放大时换到下一个商品，放大图也跟着换。不小心刷新或离开了页面也没关系：
   「已上传图片」没了的话，插件会把还没完成的商品主图重新上传，接着选。
3. **确认设为货源**：在面板里点「打开货源」（或者直接点 1688 的商品卡片打开详情页，也算正在选的那个商品），面板读出每个 1688 规格的价格和运费，
   按名称自动对应到我们的规格（名称写法不同也能对上，比如「细条纹油壶1000ml香槟色」对「水系油壶 1000ml 香槟色」），货源价自动填好；
   没对上的规格标成橙色。每个规格有「数量」（默认 1）：货源价 = 1688 单价 × 数量 + 运费，比如卖「3把装」填 3。也可以一键「按顺序对应」或「全部用」某个 1688 规格，你改过的对应关系会记住，下次自动用。
   每个规格前面显示我们商品这个规格的图片（点击放大，方便和 1688 对照）。货源没有的规格点「删除规格」，或者勾选多个（可「全选」「选未对应的」）点「删除所选规格」：微信小店里这个规格的库存改为 0（下架，
   微信没有单独删除规格的接口，删除整个规格要重新提交审核），商品管理和插件里不再显示，重新同步商品后也保持删除。
   运费会自动读取；没读到时运费框标红，必须填写（包邮填 0）才能设为货源，运费会自动加进每个规格的货源价。
   核对无误点「设为货源」，详情页会自动关闭并回到找品页。
   在网站「商品管理 → 自动改价」开启后，设为货源时会按预设公式（货源价 × 倍率 + 加价 + 优惠券）自动给这个商品改价并同步到微信小店，面板里显示新售价。
4. **跳过 = 无货源**：跳过的商品在网站上标记为「无货源」，以后不再出现在待找货源的列表里（之后设了货源会自动取消标记）。
6. **多账号不重复**：开始批量时，这些商品会记在你名下（2 小时内有效，选的过程中会自动续期）。其他账号（共享店铺、子账号）
   的待找货源列表里看不到它们，也不会分到同一批里。同一个货源商品上架到多个店铺时只算一个，只出现一次。
   设了货源、跳过、或清除批量后自动释放。一件代发搜索页和找品页都一样；批量页面打开期间，插件每 10 分钟给这一批还没完成的商品续期，
   用「换商品」输入商品 ID 时，正在被其他账号找货源的商品会提示，不能换。
5. **自动下一批**：一批 10 个商品都「已设货源」或「跳过」后，5 秒后自动取下一批 10 个还没有货源的商品（和开始时同样的店铺 / 云库范围），重新打开找品页继续。货源价（已含运费）写入商品云库和所有店铺里的同一商品，
   公式改价和订单采购成本都按这个货源价计算。插件弹窗里能看到每个商品的进度。

6b. **两阶段找货源**（插件弹窗「找货源阶段」）：
   - 第一阶段（快速判断）：每个商品只判断有没有同款——看一眼搜索结果，有同款就点插件面板里的「有货源」（不用点卡片，第二阶段再选具体货源），
     没有就点「跳过」：标记无货源，并把这个商品在所有上架店铺里的库存改为 0。有曝光的商品（优先）不受影响：仍然排在最前面、
     显示曝光，直接「选为货源」。
   - 第二阶段（精选）：只列第一阶段「有货源」的商品，按原来的流程找最优货源和价格，在结果卡片上点「选为货源」。
7. **上架优先、商品ID**：待找货源的商品先列店铺里「上架」的，再列未上架 / 草稿箱的。批量面板里每个商品显示商品ID，点「复制」，出错时可以粘到「换商品」里。
8. **先找曝光多的商品**：打开微信小店后台「商品列表」页面，左下角出现「1688 货源助手 · 曝光」，点「读取本页曝光」或「读取全部页」
   （自动点下一页），插件读出每个商品的 ID 和近30天「曝光」数存到网站；读完后框里显示有曝光的商品里还有几个没货源，
   点「给曝光商品找货源」就按曝光从多到少直接开始批量找货源（一次 10 个）。之后找货源时，上架商品里曝光多的也排在最前面。
   **优先找货源**：只要有任何账号在任何店铺读到某个商品有曝光，这个商品（同一个云库商品在各店铺里的都算）就标「优先」：
   选了店铺时，先列这个店铺里已上架且有曝光的，再列其他已上架的，最后未上架 / 草稿箱；正在被其他账号找货源的不会列出。
9. **换商品**：面板顶部输入微信小店商品 ID（订单管理里每个商品下面的「商品ID」，可以点「复制」）点「换」，
   面板就换成这个商品，在当前页面给它找货源 / 设为货源。
8. **采购跟踪**：在订单管理里点收件人的「复制」（或「复制面单地址」），到 1688 下单页点「使用临时地址」粘贴，
   插件左下角显示识别到的订单。点「立即下单」时记录下单价格（含运费）和每个商品的单价、数量；
   到收银台后自动读取 1688 订单编号，写入这个订单的「采购」：采购单号、采购实付，同时把下单时每个规格的 1688 单价
   原样记为这个订单对应规格的真实采购价（货源价，不做换算；下单的不是原货源链接也照样记录；1688 原价会保留）。同一个订单再下一单（另一个供应商）会追加采购单号、累加实付。
   识别错了点「不是这个订单」，或在框里输入正在采购的微信订单号点「换」。一个订单已经记录过 1688 订单号后，再出现新的 1688 订单不会自动追加，
   会先问你：是同一个订单就点「记录到订单…」，不是就输入正确的微信订单号。
   采购实付以收银台上要付的金额为准（含运费）；下单页上的价格在页面打开期间一直更新，点「立即下单」时再记录一次。
9. **自动发货**：1688 卖家发货后，在订单管理点采购单号旁的「1688查看」，打开 1688 订单详情，插件自动打开「物流信息」，
   读取物流公司和运单号码，给微信小店的这个订单发货（快递公司自动对应，比如「申通快递(STO)」对应申通快递）。
   直接打开 1688 订单详情（不是从订单管理点进来）时，左下角显示物流信息和「发货到微信小店订单」按钮，按采购单号找订单。
   卖家还没发货时会提示，之后再点一次「1688查看」即可。左下角会一直显示进度；没读到物流时可以在框里手动填物流公司和运单号码，点「发货到微信小店订单」。

如果没能自动上传，面板里可以「下载主图」到电脑，在 1688 点「批量图搜」选择这些图片，上传完成后点「全部重选」。

插件只在 1688 上传主图搜图、读取页面，不会替你下单、付款或提交其他任何东西；设为货源由你确认，采购跟踪只读取你自己下单时页面上的价格和订单编号。

## 安装

1. 把整个 `1688-extension` 文件夹下载到电脑上。
2. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`），打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择 `1688-extension` 文件夹。
4. 点浏览器右上角的拼图图标，把「1688 货源助手」固定到工具栏。

## 说明

- 1688 页面结构经常变化，如果某个页面读不到价格或规格，可以在面板里手动填写，然后告诉开发者页面地址。
- 搜索结果页的图片要先加载出来（往下滚动一下）才能显示「选为货源」。


## 一键上架勾选的商品（1688 搜索页）
在 1688 搜索结果页（如一件代发搜索页）勾选商品卡片，插件面板点「一键上架勾选的商品到小店」：
- 每个商品卡片左上角自动出现橙色勾选框（往下滚动加载的也有；页面自己的勾选框也算）。可以「全选本页」「清空」。换类目 / 换搜索词后，插件的勾选自动清空、重新读取。
- 勾选的商品标题会列在面板里，方便上架前检查：用鼠标选中标题里的词，点「选中文字加入违禁词」，再点「加入」。
- 勾选上架到哪些店铺（只能选已完成发布配置的），点「开始上架」。已提交的商品卡片会加绿框。
- 每个商品在后台打开它的 1688 详情页，读取标题、主图、详情图、主图视频、规格（只要有库存的）、价格、运费和商品属性，读完自动关闭，再提交上架。
- 标题：勾选「AI 重新生成标题」（默认勾选，会记住）时，用 DeepSeek 按 1688 标题、类目和商品属性重新写，长度尽量写满上货模板的「标题最大长度」（至少约 90%，微信最多 60 字；太短会让 AI 再写一次，太长按词截断），进度里显示生成的标题和字数。不勾选就用 1688 的标题。两种都按上货模板的规则处理（去掉违禁词等）。想要更长的标题，把上货模板的「标题最大长度」改成 60。
- 商品属性用 1688 的，类目要求的必填属性按模板自动补。
- 微信类目：微信接口没有按标题自动分类的功能，网站用类目库（「一键申请类目」里同步）按标题和 1688 类目匹配，系统设置里有 DeepSeek Key 时由 AI 从最接近的类目里选。店铺没开通的类目会自动提交类目申请。
- 售价 = (1688价 + 运费) × 倍率 + 加价（+ 店铺优惠券），和「自动改价」一样。没读到运费时按包邮算，会提示。
- 上架的商品也会记到商品云库（平台 1688），货源自动设好。上架结果在网站「任务列表」里看。
- 「标题违禁词」框：输入的词加入你所有上货模板的「标题违禁词」，以后上架都会从标题里去掉。管理员账号上货模板里的标题违禁词所有用户共享：任何账号上架（插件上架、云发布）时都会去掉；普通账号加的词只对自己生效。

## 框选全图（一件代发搜索页）
1688 搜图默认只搜它自动框出的「主体」（常常只是图里的一部分）。批量找货源时插件默认「框选全图」：每张图出结果后，自动点「框选主体」，把框拉满整张图，点「确认」，用整张图的搜索结果。批量列表下面的「框选全图」勾选框可以关掉（会记住）。

## 1688 上架（新流程）
商品云库的商品只用来找货源：用它的主图在 1688 搜同款，云库商品本身不再上架。
1. 在插件弹窗选「商品云库（找到就上架）」（默认，会记住上次的选择）批量找货源（或网站商品云库里点「找货源」）。
   也可以在任意 1688 页面的插件面板「换商品」框里输入云库商品ID或标题关键词，点结果里的商品直接用它。
   也可以选「共享云库（找到就上架）」：找其他账号上传、你还没加入的共享云库商品。开始批量（或在「换商品」里点它）时，商品先免费加入你的商品云库（和网站「共享云库 → 加入」一样，上架时按次扣积分），之后和商品云库商品一样找货源、1688 上架。
   注意：选「店铺商品」时是给已经在店铺里的商品设货源，不会显示 1688 上架。云库商品不走第一阶段的快速判断，会打开详情页。
2. 在搜索结果卡片上点「选为货源」，打开 1688 商品详情页。
3. 详情页的插件面板显示「1688 上架」：
   - 主图、详情图、主图视频、规格（名称、规格图、价格、库存）读取自 1688；标题、微信类目、类目属性用云库商品的。
   - 主图视频：微信不能直接用 1688 的视频链接，上架时网站先下载视频，再用微信的视频上传接口上传（商品视频最长 180 秒、最大 500MB），转码完成后放进商品；不符合要求或被微信拒绝时，不带视频上架并在任务里说明原因。
   - 勾选要卖的规格（没库存的默认不选），填运费（包邮填 0）。
   - 售价按「自动改价」的倍率和加价计算：(1688价 + 运费) × 倍率 + 加价，再加上店铺生效的优惠券金额。
   - 勾选店铺（只能选已完成发布配置的），点「上架到小店」。
4. 网站为每个店铺建一个发布任务，面板里显示每个店铺的上架结果；成功后店铺商品的每个规格货源价自动记好，采购、改价直接可用。
   也可以点「只设为货源，不上架」用原来的方式。
