# 自动收藏「新店开张」的小店（scrcpy）

在电脑上通过 scrcpy 窗口操作手机微信「小店与卡包」：像人一样用鼠标点击、用滚轮下滑，
用离线文字识别（OCR）读取屏幕，把标着 **新店开张** 的小店点 **收藏小店**。

这个工具在你自己的 Windows 电脑上运行，和服务器、网站无关。

## 流程

1. **首页（小店与卡包 · 推荐）**：按列表顺序找下一个商品卡片。
   - 左上角有橙色 **直播中** 标记的卡片：跳过，不点。
   - 卡片上写着 **收藏的店**：说明这家店已经收藏过，跳过，不点。
2. **商品页**：点击顶部的店名（如「尽酷商贸」）。如果打开的是直播或其他页面，就跳过。
3. **店铺页**：
   - 有 **新店开张** 且按钮是 **收藏小店**：点击收藏，并确认按钮变成 **已收藏**。
   - 已经是 **已收藏**：跳过。
   - 不是新店：跳过。
4. **返回首页**：点击左上角的返回箭头，直到回到首页列表。
   - 在首页本身不会点返回，因为那会退出小店。
   - 如果箭头不起作用（例如直播间），就用鼠标右键返回（scrcpy 中右键 = 手机返回键）。
5. **继续**：当前屏幕的商品都处理完后，用**鼠标滚轮**向下滚动，接着找下一批。
6. **记录**：每家店的结果写进 `shops_log.csv`。下次运行时，处理过的店会直接跳过。

## 准备

1. 安装 **Python 3.10–3.12**（python.org），安装时勾选 *Add python.exe to PATH*。
2. 手机用 scrcpy 投屏到电脑。窗口标题默认是 `ANP-AN00`（你的手机型号），换手机时用 `--window 标题` 指定。
3. 手机停在 **微信 → 小店与卡包 → 推荐** 列表页。
4. 双击 `run.bat`。第一次运行会安装依赖并下载识别模型，需要几分钟。

## 使用（run.bat 菜单）

| 选项 | 作用 |
|---|---|
| **[1] Probe** | 截取一次窗口画面并识别，显示识别到的文字、页面类型、商品卡片和店名，同时保存 `probe.png`。**第一次先用它检查识别是否正常。** |
| **[2] Dry run** | 试运行：完整走一遍流程，但不点「收藏小店」。 |
| **[3] Run** | 正式运行。默认最多检查 30 家店。 |

也可以在命令行运行，例如：

```
python follow_new_shops.py --max 50 --scroll 4 --delay 3 6
```

**停止**：按 `Ctrl+C`，或者把鼠标甩到屏幕任意一个角落（安全急停）。
运行时会占用鼠标，期间请不要使用电脑。

## 注意

- **频率**：默认每个商品之间随机等待 2–5 秒，每处理 12 个商品休息 40–90 秒，每次最多 30 家店。不要调得太快。
- **账号风险**：频繁、规律的自动操作可能被微信判定为异常，风险由使用者自行承担。
- **遇到验证会停止**：如果屏幕上出现「操作频繁」「请完成验证」等字样，程序会立即停止，等你手动处理。
- **返回箭头位置**：位置写在 `follow_new_shops.py` 的 `BACK_ARROW = (0.065, 0.071)`，表示画面宽度和高度的比例。如果点不到箭头，用 Probe 生成的 `probe.png` 量一下位置再改这里。
- **识别不准**：可以先把 scrcpy 窗口拉大一些再运行。
