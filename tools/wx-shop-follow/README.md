# Auto-Favorite：自动收藏「新店开张」的小店（scrcpy）

在电脑上通过 scrcpy 窗口操作手机微信「小店与卡包」：像人一样用鼠标点击、用滚轮下滑，
用离线文字识别（OCR）读取屏幕，把标着 **新店开张** 的小店点 **收藏小店**。

这个工具在你自己的 Windows 电脑上运行，和服务器、网站无关。

## 桌面程序 Auto-Favorite.exe（推荐）

- **在自己电脑上打包（每次更新后）**：
  - 推荐：打开项目根目录的 `deploy.bat`，选 **[B]**。它会先 `git pull` 拉取最新代码，再打包。
  - 也可以直接双击本文件夹的 `build.bat`，只打包，不拉取代码。
  - **电脑上不需要装 Python。** 打包总是使用一个**只给打包用**的 Python 3.11，和电脑上已有的 Python 互不影响。
    - 第一次打包时会自动下载安装，不需要管理员权限，也不加入系统 PATH。
    - 下载走国内镜像（npmmirror、阿里云 pip 源），失败时再用官方源。
  - 打包在全英文路径的 `C:\AutoFavoriteBuild` 里进行，避免项目路径里的中文导致出错。完成后，exe 会复制回项目文件夹。
  - 完整日志在 `C:\AutoFavoriteBuild\build.log`。打包失败时会自动用记事本打开，请复制日志发给我们排查。
  - 第一次打包大约 5–10 分钟，以后每次 1–3 分钟。
  - 打包好的程序固定放在项目根目录的 **`Auto-Favorite\Auto-Favorite.exe`**。
    - 设置、关键词、记录都在这个文件夹里，重新打包不会丢。
    - 这个文件夹不会被上传到 GitHub，也不会被 `git pull` 覆盖。
  - 打包前请先关闭正在运行的 Auto-Favorite。没关的话会提示，新版本先留在 `dist` 文件夹里。
  - bat 只用英文，不会乱码。
  - GitHub 每次修改后也会在 Windows 上用同一个 `build.bat` 打包并测试一遍，确保它能用。
- **使用**：双击 `Auto-Favorite\Auto-Favorite.exe` 运行。
  - 设置、关键词、记录（`shops_log.csv`）都保存在 exe 旁边。
  - 第一次启动需要解压，会稍慢一些。
- **界面**：
  - **scrcpy 窗口标题**：默认 `ANP-AN00`。旁边的 **检测识别** 按钮相当于下面的 Probe，会保存 `probe.png`。
  - **模式**：关键词搜索（每个关键词收藏 N 家新店，全部满了自动停止），或首页推荐（最多检查 N 家店）。
  - **试运行**：完整走一遍流程，但不点「收藏小店」。
  - **关键词**：每行一个。
  - **节奏**：每个商品之间的间隔、滚轮格数，以及每处理多少个商品休息一次。
  - **开始 / 停止**，以及每个关键词的进度和运行记录。
  - **复制记录**：复制全部运行记录，方便粘贴给别人排查问题。**清空**：清空运行记录。
- **窗口位置**：开始时，Auto-Favorite 窗口会自动移到 scrcpy 窗口旁边，避免挡住手机画面导致点错。运行中不要把它拖到 scrcpy 窗口上面。

下面是命令行版本（`run.bat`）的说明。两个版本的流程完全相同。

## 两种模式

- **关键词模式（默认）**：在首页搜索框里依次搜索 `keywords.txt` 里的每个关键词，在搜索结果里找新店。
  - 每个关键词收藏满 **30 家**新店后，自动换下一个关键词。
  - 全部关键词都满了，就自动停止。
  - 如果某个关键词的搜索结果翻到底还不够 30 家，也会换下一个，最后列出没有满的关键词。
  - 进度按关键词记在 `shops_log.csv` 里。中途停止后再运行，会从没满的关键词继续。
- **首页模式**（`--home`）：不搜索，直接刷「推荐」列表，最多检查 30 家店。

## 关键词

- 关键词写在 `keywords.txt` 里，每行一个；`#` 开头的行是注释，会被忽略。
- 第一次运行时，`keywords.txt` 会从 `keywords.example.txt` 复制出来。
- 在 run.bat 菜单里选 **[2]** 可以直接打开编辑。
- 这个文件只属于你自己，更新代码时不会被覆盖。
- 关键词是中文，无法用模拟按键输入。程序会先把关键词放进电脑剪贴板，再按 Ctrl+V，由 scrcpy 粘贴到手机里。

## 流程（每个商品）

1. **列表（首页推荐，或搜索结果）**：按列表顺序找下一个商品卡片。
   - 左上角有橙色 **直播中** 标记的卡片：跳过，不点。
   - 卡片上写着 **收藏的店**：说明这家店已经收藏过，跳过，不点。
2. **商品页**：进入店铺。
   - 底部有 **小店** 按钮（搜索结果打开的商品页，在「客服」旁边）：点击这个按钮。
   - 没有这个按钮：点击顶部的店名（如「尽酷商贸」）。
   - 店名从店铺页读取，处理过的店会跳过。
   - 如果打开的是直播或其他页面，就跳过。
3. **店铺页**：
   - 有 **新店开张** 且按钮是 **收藏小店**：点击收藏，并确认按钮变成 **已收藏**。
   - 已经是 **已收藏**：跳过。
   - 不是新店：跳过。
4. **返回列表**：点击左上角的返回箭头，直到回到列表（首页推荐或搜索结果）。
   - 在首页本身不会点返回，因为那会退出小店。
   - 如果箭头不起作用（例如直播间），就用鼠标右键返回（scrcpy 中右键 = 手机返回键）。
5. **继续**：当前屏幕的商品都处理完后，用**鼠标滚轮**向下滚动，接着找下一批。
   - **首页模式**：每看 30–50 个商品（随机），就回到首页顶部下拉刷新，换一批推荐。列表看到底时也会刷新，而不是停止。在 Auto-Favorite 窗口里可以改这个范围。
6. **记录**：每家店的结果写进 `shops_log.csv`。下次运行时，处理过的店会直接跳过。

## 准备

1. 安装 **Python 3.10–3.12**（python.org），安装时勾选 *Add python.exe to PATH*。
2. 手机用 scrcpy 投屏到电脑。窗口标题默认是 `ANP-AN00`（你的手机型号），换手机时用 `--window 标题` 指定。
3. 手机停在 **微信 → 小店与卡包 → 推荐** 列表页。
4. 双击 `run.bat`。第一次运行会安装依赖并下载识别模型，需要几分钟。

## 使用（run.bat 菜单）

| 选项 | 作用 |
|---|---|
| **[1] Probe** | 截取一次窗口画面并识别，显示识别到的文字、页面类型、商品卡片和店名，同时保存 `probe.png`。**第一次先用它检查识别是否正常。** |
| **[2] Keywords** | 用记事本编辑关键词（`keywords.txt`）。 |
| **[3] Dry run** | 关键词模式试运行：完整走一遍流程，但不点「收藏小店」。 |
| **[4] Run** | 关键词模式正式运行：每个关键词收藏 30 家新店，全部完成后自动停止。 |
| **[5] Home feed** | 首页模式：不搜索，刷推荐列表，最多检查 30 家店。 |

也可以在命令行运行，例如：

```
python follow_new_shops.py --per-keyword 20 --scroll 4 --delay 3 6
python follow_new_shops.py --home --max 50
```

**停止**：按 `Ctrl+C`，或者把鼠标甩到屏幕任意一个角落（安全急停）。
运行时会占用鼠标，期间请不要使用电脑。

## 注意

- **频率**：默认每个商品之间随机等待 2–5 秒，每处理 12 个商品休息 40–90 秒。关键词模式会一直运行到所有关键词都满 30 家，时间可能很长，可以随时停止，下次会接着做。不要调得太快。
- **账号风险**：频繁、规律的自动操作可能被微信判定为异常，风险由使用者自行承担。
- **遇到验证会停止**：如果屏幕上出现「操作频繁」「请完成验证」等字样，程序会立即停止，等你手动处理。
- **返回箭头位置**：位置写在 `follow_new_shops.py` 的 `BACK_ARROW = (0.065, 0.071)`，表示画面宽度和高度的比例。如果点不到箭头，用 Probe 生成的 `probe.png` 量一下位置再改这里。
- **识别不准**：可以先把 scrcpy 窗口拉大一些再运行。
